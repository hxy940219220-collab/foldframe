# Foldframe

Foldframe 是本地 AI 内容创作工作台，可以规划草稿、管理生成的图片和视频，并通过已授权的频道发布内容。模型调用取决于当前实例配置的服务和凭证。

## 工作台入口

- [创作首页](/zh-CN)：编写提示词、添加参考素材、创建草稿并浏览媒体资源。
- [AI 发布](/zh-CN/ai-social)：通过 Agent 和创作技能处理内容。
- [发布](/zh-CN/accounts)：管理频道并安排发布。
- [AI 生成素材](/zh-CN/agent-assets)：查看生成的素材。
- [技能管理](/zh-CN/skills)：搜索、筛选和阅读当前安装的 Agent 技能。
- [用量统计](/zh-CN/usage)：查看当前账号按日期、模型及生成类型汇总的 Token、已上报费用及媒体用量。
- [任务记录](/zh-CN/tasks-history)：查看任务状态与历史记录。
