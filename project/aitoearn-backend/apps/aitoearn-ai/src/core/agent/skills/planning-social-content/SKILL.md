# 多平台运营策划全案（Social Content Planning）

将单一创意主题、产品卖点或参考素材，快速转化为适配多平台原生语感的成稿、短视频分镜、带货种草链路及周度发布日历。

## 适用场景

当用户提出以下任一需求时自动激活本技能：

- **一鱼多吃 · 跨平台改写**：围绕同一产品或观点，同步输出小红书、抖音、B站、X (Twitter)、Instagram、YouTube、视频号等平台原生语感文案
- **爆款短视频分镜全案**：策划 15–60 秒短视频的前 3 秒钩子、镜头分镜表、画面提示词、口播台词、BGM 节拍与高点击封面标题
- **商品种草转化全链路**：提炼核心痛点与差异化卖点、规划首图与内页视觉构图方案、撰写高转化种草正文与评论区置顶引导话术
- **热点选题与一周排期**：围绕赛道关键词规划差异化选题方向、7 天多平台发布节奏表、内容形式配比与最佳发布时段

## 四大标准作业模板

### 模板一：一鱼多吃 · 跨平台改写（高频必备）

输入一个核心主题、产品卖点或参考图，按用户勾选的目标平台分别交付原生风格成稿：

1. **小红书（种草图文）**
   - 3 个高点击率备选标题（痛点/反差/数字型，控制 20 字内 + 适度表情符号）
   - 分段式情绪价值正文（痛点共鸣 → 核心体验 → 细节佐证 → 互动提问）
   - 5–8 个精准流量标签（大词 + 垂直词 + 场景词）
2. **抖音（短平快口播）**
   - 0–3 秒黄金停滑钩子（画面动作 + 强冲击开场白）
   - 15–30 秒紧凑口播正文（口语短句，节奏明快，标注停顿与重音）
   - 结尾互动/转化 CTA 与 3–5 个热搜话题标签
3. **B站（硬核测评 / 动态）**
   - 有信息量、带「真实实测感」的标题与开场引入
   - 结构化干货要点（对比参数 / 避坑指南 / 真实体验）
   - 自然的「一键三连」与弹幕/评论区话题互动话术
4. **X / Twitter（精炼推文 / Thread）**
   - 1 条强观点 Hook 主推 + 2–4 条信息密度高的连推 Thread（支持中英双语或纯英文出海）
   - 每条控制在 280 字符内，结尾自然引导转发/收藏
5. **Instagram / YouTube / 视频号**
   - 按目标平台自动适配视觉大片配文、Shorts/长视频大纲或私域熟人转发话术

### 模板二：爆款短视频分镜全案（脚本 + 出片）

按「可直接交给拍摄或 AI 生图/生视频执行」的标准交付：

1. **核心创意与前 3 秒钩子**：明确视觉冲击点、情绪触发词与首帧定格画面
2. **分镜执行表**（Markdown 表格，5–8 个镜头）：
   - 镜号与时长（如 `0-3s`、`3-6s`）
   - 景别与运镜（特写/推进/环绕/跟拍）
   - 画面描述与 AI 生图/生视频提示词（可直接用于视觉创作台）
   - 同期口播台词与屏幕花字字幕
3. **声画节奏与封面方案**：BGM 风格与卡点节拍建议 + 2 套高点击率封面主副大字方案

### 模板三：商品种草转化全链路（带货转化）

围绕单品或套装构建「看图停滑 → 正文种草 → 评论拔草」闭环：

1. **用户痛点与 3 大差异化卖点提炼**（避开空泛形容词，用场景化对比表达）
2. **4 张首图 + 内页视觉构图方案**：每张给出构图视角、光影氛围、卖点贴纸文案与 AI 生图参考提示词
3. **高转化种草正文**：真实使用场景切入 + 解决痛点细节 + 购买决策助推
4. **评论区置顶与神评引导话术**：3 条模拟真实提问与高情商回复模板，拉高互动与转化

### 模板四：热点选题与一周排期（运营规划）

面向垂直赛道账号规划可执行的一周内容增长日历：

1. **3 个差异化高潜选题方向**：分别说明切入角度、受众痛点与爆款潜质
2. **7 天发布排期表**（Markdown 表格）：
   - 日期（Day 1 – Day 7）
   - 目标发布平台
   - 选题标题与内容形式（图文 / 短视频 / 动态）
   - 建议发布时段与核心运营目标（涨粉 / 种草 / 互动 / 转化）
3. **素材复用建议**：标出哪几天可「一鱼多吃」复拍复剪，降低创作者制作成本

## 执行规范

1. 始终使用用户的语言回复，默认输出结构清晰、可直接复制发布的成品内容。
2. 若用户已指定【目标分发平台】，严格只展开这些平台，不冗余堆砌未选平台。
3. 若用户同时要求配图或成片，可在文案/分镜方案完成后主动调用 `generateImage` 或 `generateVideo` 生成首图或关键分镜。
4. 输出结束后，提示用户可将满意文案与视觉素材直接带入「排版工坊」进行 7 平台手机仿真预览与排期分发。
