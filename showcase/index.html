7 大核心功能全流程拆解

所有界面均为本地实跑 2880×1800 超清截屏，点击任意图片可放大查看细节。

01

内容创作工作台：商业生图、生视频、写文案一站完成

在一个界面里就能完成商业产品主图、写实人物照、品牌海报、宣传短视频和图文文案生成。支持直接拖入参考图，点开任意一张成品还能在右侧看到提示词、所用模型、尺寸与积分消耗，方便团队复盘和复用。

商业产品图 写实人像与海报 宣传短视频 图文文案草稿
02

无限画布：把素材铺开整理，选中图片就能继续改图出新

进入画布后，所有图片和视频会自动居中排开，不用在文件夹里来回翻找。点中任意一张图，下方就会直接弹出提示词和模型、比例、清晰度设置，改两句话就能继续生成新版本；也能把几张素材连上线作为参考，边做边让 AI 助手帮忙出创意。

自动居中排布 点图直接改词出图 多素材连线参考 AI 助手对话
03

多维改图：不用写复杂提示词，按 6 个方向精准微调画面

选好一张人物照或产品主图后，直接按「换镜头角度、换光影氛围、换背景场景、换画风质感、换穿搭造型、换表情动作」六个方向微调。每项内置了常用下拉选项，也可以点开修改提示词再生成；还能一键批量出 4 张，或选 2 张图直接转成宣传短视频。

6 维可视化预设 支持编辑提示词 批量生成 4 张 首尾帧转视频
04

AI 生成素材库：按类型与画面比例快速筛选所有图片和视频

所有生成的商业产品图、写实人物、品牌海报和宣传短视频都会自动沉淀在这里。顶部支持按「全部 / 图片 / 视频」分类，以及按「竖版 / 横版 / 方图 / 9:16 / 3:4 / 1:1 / 16:9」一键筛选，每张卡片自动标注类型和真实比例，找素材一目了然。

图片 / 视频分类 多比例快速筛选 自动标注 3:4 / 1:1 / 16:9
05

排版工坊：所见即所得的手机端预览与图文 / 视频分流

入口处把「图文发布」和「视频发布」彻底分开。左侧点击「+」号即可从本地上传或直接从素材库选图，标题、正文和话题标签都能让 AI 一键辅助生成；右侧仿真手机实时呈现小红书、抖音和 Instagram 的发布效果，手机旁还能一键切 3:4 / 1:1 / 4:3 / 原图、拖动微调构图、手动裁剪或按目标比例重构画面。

图文 / 视频彻底分开 仿真手机实时预览 竖排比例与裁剪工具 AI 写标题与正文
06

发布待办：多平台账号统一管理、排期与一键分发

做好的图文和视频可以直接流转到「发布待办」进行日历排期和跨平台分发。支持统一接入小红书、微信视频号、微信公众号、快手、B站、YouTube、TikTok、Instagram、Facebook、X (Twitter)、Threads、LinkedIn、Pinterest 等 13 个国内外主流内容平台，真正打通「做完即发布」的最后一公里。

13 个国内外社媒平台 日历定时排期 多账号统一管理 一键跨平台发布
07

本地模型接入：直连本机 Antigravity、Codex、即梦与第三方 API

不被单一云端平台锁定。支持直接接入电脑本机已登录的 Antigravity、Codex（含 ChatGPT / GPT 生图）、即梦 AI（5.0 生图 / Seedance 视频） 以及本地离线 Ollama，也可按需填写真实第三方 API Key（OpenAI / DeepSeek / Gemini 等），并为「内容 Agent、文案草稿、图片生成、视频生成」分别指定默认模型。

本机 Antigravity 本机 Codex / GPT 生图 即梦 5.0 / Seedance 分场景模型路由
