从灵感到发布的五段真实工作流

以下均为本地容器实跑截屏，不以概念稿替代真实交互。

01

内容创作 · 快捷工作台

收拢式提示词栏支持拖拽上传参考图，并把「生成草稿（图文/视频）」与「生图 / 生视频」清晰解耦：草稿模式直连本机大语言模型生成结构化文案，图片与视频走独立多模态管线，点开任意成品即可在右侧查看提示词、模型、尺寸与真实积分消耗。

纯 LLM 草稿 拖拽参考图 生成详情侧栏
02

无限画布 · 节点连线与 Agent 协作

进入画布自动收起侧栏并水平居中展示已有资产，支持平滑阻尼缩放与一键居中整理；点击任意图片或视频节点时，下方就近弹出可编辑的参数与提示词面板，并可通过节点连线把多张图/视频串成二次衍生参考工作流。

自动居中画布 就近参数浮窗 图文/视频互连
03

多维改图 · 可控二创实验室

围绕中心完整原图展开六个通俗维度（换镜头角度、换光影氛围、换背景场景、换画风质感、换穿搭造型、换表情动作）。每项内置景别/角度/风格等下拉预设，并可展开微调提示词后显式触发生成；参考图支持二次确认删除与多图首尾帧转视频。

六维预设 + 改词 原比例完整展示 删除二次确认
04

AI 发布 · 仿真手机排版工坊

独立归属到「AI 发布」栏目下，入口即彻底隔离「图文发布」与「视频发布」。左侧精简为唯一「+」号（本地上传 / 资产库选择）与 AI 辅助写作卡；右侧仿真手机实时映射小红书、抖音与 Instagram 的笔记/封面效果，手机右侧竖排比例栏整合画幅切换、自由裁剪与按比例 AI 重构。

图文/视频分流 竖排比例工具栏 拖拽取景 + 比例重构
05

AI 生成素材库 · 类型与比例速筛

集中沉淀所有 AI 生成的图片与视频素材。顶部提供「全部 / 图片 / 视频」分类计数与比例下拉筛选（竖版、横版、方图及 9:16 / 3:4 / 1:1 / 16:9 等），前端自动识别真实像素尺寸并标注角标，点击大图即可回溯生成模型、参数与提示词。

类型 + 比例筛选 像素比例自动识别 可回溯生成元数据

本机多模型桥接与工程架构

基于 MIT 开源底座深度定制，所有模型凭证与生成资产均可留在本地闭环运行。

01 / Local Bridge

宿主机 CLI 引擎桥接

通过 scripts/local-bridge.mjs 统一编排本机已登录的 即梦 CLI（5.0 Lite / 5.0 Pro / 4.5 / Seedance 2.0 & 2.5）、Codex CLI（GPT Image 2 + 文本） 与 Antigravity CLI，容器内服务通过受 Token 保护的本地网桥安全调用。

02 / Media & Metering

真实积分与元数据追踪

生图与视频任务执行前后自动采集引擎余额差值，区分真实扣费与活动限免，并将提示词、模型、画质、比例和耗时持久化写入任务元数据，支撑画布节点复用与资产回溯。

03 / Self-Hosted Stack

全栈容器一键拉起

Next.js 14 前端 + NestJS 微服务（aitoearn-server / aitoearn-ai）+ MongoDB 副本集 + Redis + RustFS 对象存储 + Nginx 反向代理，本地双击 启动本地版.command 即可运行。
